# Project Description

Parking Lot Management System is a Java-based application designed to manage a multi-floor parking facility.

The system allows users to:

- Register vehicle entries.
- Register vehicle exits.
- Automatically assign parking spaces.
- Manage employees.
- Generate parking tickets.
- Process payments.
- Search vehicles, tickets, employees and parking spots.
- Generate reports and statistics.
- Analyze parking information through the ParkingAI module.
- Persist data using serialization.

Supported vehicle types:

- Cars
- Motorcycles
- High-displacement motorcycles
- Disabled vehicles
